# is-a.stupid.cat Website

The public-facing site for [is-a.stupid.cat](https://is-a.stupid.cat) — free
`*.is-a.stupid.cat` subdomains.

This is just the website. To register a subdomain, open a PR on
[is-a-stupid-cat/register](https://github.com/is-a-stupid-cat/register).

Subdomains are free and must not be used for commercial organisations, crypto/NFT projects,
or adult content — see the [Terms of Service](https://is-a.stupid.cat/terms).
